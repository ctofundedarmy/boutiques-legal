# Boutiques legal pages

Privacy policy and account-deletion page for the Boutiques app (FundedArmy, Rewari), served by GitHub Pages.

- Source text: `src/*.md` (copied from the app repo's `docs/`).
- Build: `python3 build.py` writes `privacy-policy/index.html`, `delete-account/index.html` and `index.html`. Commit the output; Pages serves it as is.
